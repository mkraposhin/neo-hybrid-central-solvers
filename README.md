This repository stores a port of [hybrid central solvers](https://github.com/unicfdlab/hybridCentralSolvers)
to [NeoFoam](https://github.com/exasim-project/NeoFOAM). The port is implmented as a
solver neoPimpleCentralFoam.

The main branch keeps this README and primary documentation.
The code is stored in other branches:

- [develop](https://github.com/mkraposhin/neo-hybrid-central-solvers/tree/develop)
keeps the latest working code;
- [draft](https://github.com/mkraposhin/neo-hybrid-central-solvers/tree/draft)
keeps the initial draft;
- [patches](https://github.com/mkraposhin/neo-hybrid-central-solvers/tree/patches)
holds patches for NeoN/NeoFOAM.
